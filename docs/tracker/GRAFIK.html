Progres SIMRS Gramedika

Dihitung otomatis oleh node tools/tracker.mjs dari katalog tile, source Java Khanza, kode produksi, dan status.json. Angka di bawah selalu mencakup seluruh data; filter hanya memengaruhi peta kotak.

Ringkasan

Status alur pelayanan

  • Kasir Rawat Jalan mencakup registrasi, tindakan, penunjang, obat kunjungan, dan kuitansi PDF.
  • Kasir Rawat Inap mencakup kamar sampai pulang, tindakan, penunjang, dan obat pulang.
  • Uji transaksi memakai data sintetis. Rekonsiliasi saldo suspen dan konfigurasi rekening RS dengan Khanza Java masih terbuka.

Prioritas berikutnya · Handover proyek

Per jenis entri

Alur yang sudah diaudit

Satu baris per file Java yang punya minimal satu entri berstatus kurang, sebagian, atau selesai. "Dinilai" = kurang + sebagian + selesai.

Peta entri

Catatan: "selesai" berarti alur setara Java dengan bukti, bukan kesiapan produk. "Layar tersedia" berarti rute layar terdeteksi di kode, belum tentu alurnya benar. "Belum diaudit" tidak berarti belum dibuat.
