# Sesi 09 — DlgReg, handover, dan EXE lokal

Tanggal: 24 November 2026. Permintaan terbaru: prioritaskan DlgReg/Registrasi, lalu siapkan EXE lokal, perbarui dokumen dan tracker, dan push ke master. Periksa `git status`/`git log` untuk kondisi Git aktual; build lokal bukan rilis GitHub.

## Pekerjaan

- Registrasi baru: `RegistrasiView` memiliki tombol Cari pasien berdasarkan nama atau nomor RM. Pemilihan mengisi data pasien dan tombol hanya aktif dalam mode Baru. Perubahan nomor RM membersihkan isian lama; hasil pemuatan yang terlambat untuk nomor berbeda diabaikan. Pilihan dibatasi 100 hasil. Mendaftarkan pasien baru dari dialog, uji database pemilih dan uji interaksi dialog lengkap masih tertunda.
- Tab Rujukan Internal Poli menampilkan daftar baca saja melalui `RujukanInternalService`, dengan dokter dan poli tujuan, periode, kata kunci dan pemeriksaan hak `registrasi`. Tombol dan input registrasi awal dinonaktifkan saat tab rujukan aktif agar tidak menindak baris dari tab lain. Menu konteks, hapus dan operasi lain, cetak, serta uji UI bersama database masih tertunda.
- Tracker dari Claude dipertahankan: `node tools/tracker.mjs` menghasilkan `fitur.tsv`, ringkasan dan data grafik; hook `.githooks/pre-commit` aktif melalui `core.hooksPath` pada clone ini. Lihat [tracker](../tracker/README.md), [grafik](../tracker/GRAFIK.html) dan [audit Registrasi](../tracker/AUDIT_REGISTRASI.md). Grafik menghitung entri inventaris, bukan persentase kesiapan produk.

## Verifikasi

- Tes keseluruhan Debug: **156 lulus, 4 dilewati**, tanpa fixture database opt-in. Tes headless mencakup mode Baru, pembersihan isian pasien, dan penonaktifan tombol pada tab rujukan.
- Tes rujukan internal dengan fixture MariaDB 11.4.8 sintetis terpisah: **2 lulus**. Memeriksa hak akses, periode, filter dokter/poli tujuan dan kata kunci. Database dan server uji lokal telah dihentikan; belum ada uji pada salinan RS atau bersamaan dengan Khanza Java.
- Publish Release win-x64 self-contained berhasil. EXE `dist/release-local-20261124-dlgreg/SimrsKhanza.UI.exe`, 59.747.626 byte, SHA-256 `53360E1B568FAF894B33909A5F8D3DAF5B50EBF17A8ED1F3F96FF6B8ACE1C94E`. Uji awal: proses bertahan 8 detik; ini bukan uji alur pelayanan.
- Publish mencatat NU1900 karena layanan audit NuGet tidak dapat diakses. Tes sebelumnya juga mencatat advisori NU1902 pada MySqlConnector 2.5.0 dan peringatan EF1002 di `RanapMenuRepository`; perlu ditinjau. EXE tetap lokal dan tidak dimasukkan ke Git.
