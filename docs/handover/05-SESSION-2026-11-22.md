## 7. Pelajaran teknis (jebakan yang sudah kena)

1. Bash heredoc yang berisi tanda kutip tunggal atau panjang bisa gagal di Windows (`unexpected EOF`, `ENAMETOOLONG`). Tulis skrip/file lewat alat Write, jalankan skrip kecil.
2. Pencocokan teks multi-baris di skrip Python harus menjaga CRLF (`newline=''`) karena file C#/XAML memakai CRLF.
3. Urutan inisialisasi field statis C#: deklarasikan array kolom bersama sebelum kamus yang memakainya.
4. Kunci tile di katalog bisa berbeda huruf besar-kecil (`BtnJadwal` vs `btnJadwal`); tracker membandingkan lowercase.
5. Tiap FK `nip` bisa menunjuk `pegawai.nik` atau `petugas.nip`; cek `schema_sik.sql` sebelum memilih sumber petugas.
