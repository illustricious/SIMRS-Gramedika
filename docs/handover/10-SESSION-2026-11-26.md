## Verifikasi dan batas

- MariaDB 11.4.8 lokal sintetis dengan fixture Kasir/Farmasi, Ralan, Ranap, dan Tindakan Ranap menghasilkan 160 lulus, 5 dilewati pada sesi implementasi. Akun, rollback paksa insert detail jurnal, klik ganda, dua kasir, dan pembacaan kuitansi ulang diuji.
- Fixture Ranap menghasilkan Rp1.086.195, sama dengan rumus SQL pembanding dari sumber Java. Jurnal menutup suspen yang sudah dibentuk saat pelayanan dan mengkredit pendapatan untuk selisih. Cabang Java yang ditinjau mengkredit pendapatan langsung. Rekonsiliasi dengan klien Java di salinan data RS masih terbuka.
- EXE lokal terakhir `dist/release-local-20261126-pelunasan-ranap/SimrsKhanza.UI.exe` membuka layar login. File EXE tidak disimpan di Git.
- Pelunasan deposit/piutang, retur, operasi, penyesuaian, penggabungan kunjungan dan layanan tambahan masih mengikuti batas di [audit pelayanan inti](../tracker/AUDIT_PELAYANAN_INTI.md). Database produksi dan printer fisik belum diuji.
