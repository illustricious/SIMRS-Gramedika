# Status Menu P

Semua 45 tile Menu P membuka layar. Cakupan layar bukan jaminan kesetaraan fungsi dengan Khanza.

| Kelompok | Layar Avalonia |
|---|---|
| Referensi surat (Indeks, Map, Almari, Rak, Ruang, Klasifikasi, Status, Sifat, Stts Balas) | Edit kode dan nama. Tidak dihapus dari layar ini |
| Surat Masuk, Surat Keluar | Edit register surat dengan almari, rak, map, ruang, sifat, status balas, status, dan klasifikasi. No. urut diisi manual. Penomoran otomatis per klasifikasi, disposisi, dan kendali surat dilakukan di Khanza. Berkas hanya menyimpan lokasi atau URL |
| Master Menolak Anjuran Medis | Edit alasan penolakan |
| Template Persetujuan Penolakan Tindakan | Edit template (diagnosa, tindakan, indikasi, tata cara, risiko, biaya, dan lainnya). Biaya tidak boleh negatif |
| Pengumuman E-Pasien | Edit. Kunci adalah pegawai dan tanggal-jam |
| 15 surat keterangan pasien | Baca. Sakit, Sakit Pihak 2, Hamil, Cuti Hamil, Surat Kontrol, Bebas Narkoba, Covid, Rawat Inap, Sehat, Bebas TBC, Buta Warna, Bebas Tato, Layak Terbang, Berobat, Kewaspadaan Kesehatan |
| 16 persetujuan dan pernyataan | Baca. Persetujuan/Penolakan Tindakan, Pulang Atas Permintaan Sendiri, Pernyataan Pasien Umum, Persetujuan Umum, Persetujuan Rawat Inap, Penundaan Pelayanan, Penolakan Anjuran Medis, Pemeriksaan HIV, Memilih DPJP, Serah Terima Barang/Anggota Tubuh, Bimbingan Rohani, Perlindungan dari Kekerasan, Permohonan Privasi, Second Opinion, Penolakan Resusitasi, Cuti Perawatan |

Daftar surat pasien memakai filter tanggal surat, pencarian nomor surat, No. Rawat, No. RM, nama pasien, dan isi surat, serta ekspor CSV. Surat diisi, ditandatangani, dan dicetak di Khanza dari data kunjungan. Tabel antrian persetujuan (`antri*`) tidak ditampilkan.
