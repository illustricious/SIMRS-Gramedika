# Status Menu N dan R

Semua 11 tile Menu N dan 10 tile Menu R membuka layar. Cakupan layar bukan jaminan kesetaraan fungsi dengan Khanza.

## Menu N: Unit Transfusi Darah

| Tile | Layar Avalonia |
|---|---|
| Komponen Darah | Edit. Total dihitung otomatis dari jasa sarana, paket BHP, KSO, dan manajemen. Biaya pembatalan tidak masuk total. Tidak dihapus |
| Pendonor Darah | Edit identitas, golongan darah, resus, dan wilayah. Nomor pendonor diisi manual. Tidak dihapus karena terkait riwayat donor |
| Donor Darah | Baca. Hasil uji saring (HBsAg, HCV, HIV, sifilis, malaria) dan status Aman atau Cekal |
| Pencekalan Darah | Baca. Donor yang dicekal dan petugas pemusnahan |
| Pemisahan Darah | Baca. Satu baris per kantong hasil pemisahan |
| Stok Darah | Baca. Tanpa filter tanggal. Kolom Lewat Kadaluarsa menandai kantong berstatus Ada yang sudah lewat tanggal |
| Penyerahan Darah | Baca. Jumlah kantong dan total per penyerahan |
| Pengambilan BHP Medis dan Non Medis | Baca |
| BHP Medis Rusak dan Non Medis Rusak | Baca |

Transaksi donor, pemisahan, penyerahan, pengambilan, dan pencatatan barang rusak dilakukan di Khanza karena memengaruhi stok dan jurnal.

## Menu R: PCRA/ICRA

| Tile | Layar Avalonia |
|---|---|
| Jenis Aktivitas, Lokasi & Kelompok Risiko Area, Kelas Risiko, Tindakan Pengendalian, Persyaratan Harus Dipenuhi | Edit referensi (kode dan nama). Tidak dihapus dari layar ini |
| Identifikasi Risiko Infeksi, Keselamatan, Kebakaran, Utilitas | Edit referensi (kode dan nama). Tidak dihapus dari layar ini |
| Pengkajian Risiko Pra Konstruksi | Baca. Ringkasan proyek, aktivitas, kelas risiko, dan perlu tidaknya ICRA. Pengisian pengkajian beserta detail risiko, persyaratan, dan pengendalian dilakukan di Khanza |
