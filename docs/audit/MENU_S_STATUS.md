# Menu S · Store, Minimarket, and Cooperative

All 25 tiles open a screen in the original dashboard order and use the existing Khanza tile permissions. The screens use the existing `sik` tables.

| Tile | Avalonia workflow |
|---|---|
| Satuan Barang | Shared editable unit master |
| Suplier Toko | Search, create, and edit suppliers |
| Jenis Barang Toko | Search, create, edit, and delete unreferenced categories |
| Barang Toko | Search, create, edit prices and product data, and activate or deactivate items. New items start with zero stock |
| Stok Opname Toko | Saved stock counts, discrepancies, and adjustment values |
| Riwayat Barang Toko | Recorded stock events, including save and delete entries |
| Pengajuan Barang Toko | Request lines, staff, and approval status |
| Surat Pemesanan Toko | Purchase order lines and order status |
| Penerimaan Barang Toko | Receipt lines by receipt date, with supplier, invoice, and payment status |
| Pengadaan Barang Toko | Direct purchase lines and payment account |
| Member Toko | Search, create, and edit members |
| Penjualan Toko | Sale lines, sales tier, and payment method |
| Piutang Toko | Credit sale lines, sales tier, and due date |
| Retur Ke Suplier Toko | Supplier return lines and original invoice |
| Retur Jual Toko | Sales return lines and original sales receipt |
| Retur Piutang Toko | Credit return lines and original credit receipt |
| Hutang Toko | Unpaid and partly paid invoices with balances calculated from recorded payments |
| Bayar Pesan Toko | Recorded supplier payments and payment accounts |
| Pendapatan Harian Toko | Daily sale and credit invoice values by staff member. Credit invoice values include receivables |
| Penjualan Harian Toko | One row per sales receipt with recorded totals |
| Piutang Harian Toko | One row per credit receipt showing down payment and credit at the time of the receipt |
| Keuntungan Barang Toko | Gross margin per sale or credit line using the purchase price stored on that line |
| Bayar Piutang Toko | Recorded customer installments and ledger accounts |
| Sirkulasi Barang Toko | Current stock and seven types of period movements. Stock value uses base cost |
| Sirkulasi Barang Toko 2 | Movements from the first stocktake in the period and calculated opening and closing stock. When that count is missing or zero, the calculation uses current stock as in Khanza |

The 20 transaction and report screens support search and CSV export. Hutang Toko lists all open invoices and supports due-date text search. The other reports have date filters. Product prices are entered manually. Supplier and member records are retained for transaction history.

Use Khanza to record or reverse transactions, approve requests, adjust stock, post accounting entries, and print legacy receipts and reports.
